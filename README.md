# 🎓 Student Marks Report System

My first Python project, created to practice programming fundamentals and improve my problem-solving skills.

## 📌 About the Project

The Student Marks Report System is a simple Python program that takes students' marks, calculates their total and percentage, and displays their academic results.

## ✨ Features

- Accepts marks for multiple students.
- Takes marks for five subjects:
  - English
  - Mathematics
  - Computer Science
  - Urdu
  - Physics
- Validates marks to ensure they are within the range of 0–100.
- Calculates total marks and percentage.
- Determines whether a student has passed or failed.
- Assigns grades based on percentage.
- Practices loops, functions, and conditional statements.

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

**Step 1:** Make sure Python 3 is installed on your system.

**Step 2:** Open the terminal in the project directory.

**Step 3:** Run the program:

```bash
python3 main.py
```

Replace `main.py` with your Python file's actual name if it is different.
